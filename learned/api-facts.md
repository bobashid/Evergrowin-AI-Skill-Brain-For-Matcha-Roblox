# Learned: API facts and signatures

Proven by a probe, log or the docs. Format: `Confirmed (YYYY-MM-DD): <fact>. Proof: <source>.` When a fact corrects an `api-*` reference file, fix that line there too and note it in `learned/corrections.md`.

- Confirmed (2026-10-26): **`require(<ModuleScript instance>)` fails in Matcha** - `pcall(require, ToolStorage.HK416.ACS_Settings)` returned `false` with a string error, not a table. Any script that calls `require` on a game module to read its live settings table cannot work; read the fields with `getgc` or `decompile` instead. Proof: matcha_exec printing `require ok false string`, Realistic Home Defense place 105527962898452.
- Confirmed (2026-10-26): **a full `getscripts()` + decompile-everything sweep exceeds the 30 s tool timeout** and returns nothing at all (no partial output). Find a script by name, or decompile one candidate, never scan all loaded scripts in one call. Proof: matcha_exec timed out after 30 s on that sweep, same game.
- Confirmed (2026-10-26): `isrbxactive` is nil inside `matcha_exec` (the MCP sandbox), even though it is a real function in a script pushed through the loader. The runtime returned a hint saying so: `hint: matcha_exec runs in a sandbox where isrbxactive is nil`. Consequence: a probe can never prove whether input lands, because the focus check is unavailable there. Proof: `matcha_exec` printing `focus=err` plus the runtime hint, Piano Rhythm Tiles.
- Confirmed (2026-10-26): a `matcha_exec` chunk is capped at **200 local variables** - `Matcha: error: too many local variables (limit is 200, got 205)`. Wide probes silently die; prefer table fields over many locals. Proof: piano timing probe that errored, then the trimmed version that ran.
- Confirmed (2026-10-26): `getgc("laneAt")` returned 5 entries whose `value` is a **string**, not the module table, so `getgc` cannot reach a game module's `press` method by key name. Proof: `matcha_exec` printing `vtype=string press=nil` for every hit.
- Confirmed (2026-10-26): `RunService.PreRender` is nil in the current build (`type(...) == "nil"`), while `RenderStepped` and `Heartbeat` are tables and `:Connect` works. Use `RenderStepped`, not `PreRender`. Proof: `matcha_exec` printing `pre=nil render=table hb=table` in Piano Rhythm Tiles (place 101999883467300).
- Confirmed (2026-10-26): `keypress`, `keyrelease`, `isrbxactive` all exist as functions for a loader-pushed script, and `mouse1press`/`mouse1release`/`mouse1click`/`mousemoveabs`/`firetouchinterest`/`fireclickdetector` all exist and return `ok=true` under `pcall`. Proof: `matcha_exec` global sweep.
- Confirmed (2026-10-26): a GuiObject's `AbsolutePosition` can be frozen at one value while the board is idle (a tile read y = 364 and y = 1104 unchanged across many samples), but it takes a full spread of values during a live chart. A never-changing `AbsolutePosition` means "this element is not animating right now", not "the VM cannot read it". Proof: idle probes vs the live 8-tile snapshot (y from -194 to 1004).
- User-stated (2026-10-26): `fireproximityprompt(prompt)` returns true on a `MountDinosaur` ProximityPrompt and completes the mount with no range check. Proof: Ride A Dino dump, header "fireproximityprompt exists and returns true on that prompt", place 93523763376122.
- User-stated (2026-10-26): `Humanoid.Sit` reads nil for a saddle mount (no Seat or VehicleSeat exists). Use a `CarriedDino` child or a seat/weld named seat, mount or saddle instead. Proof: Ride A Dino dump.
- User-stated (2026-10-26): `plot:GetAttribute('Owner')` returns the owning player's UserId as a number on Ride A Dino plots under `Workspace.Pens`. Proof: Ride A Dino dump.
- User-stated (2026-10-26): `UI.GetValue(id)` and `UI.GetValue(name)` both answer in the build used by Ride A Dino; the id form is tried first. Proof: Ride A Dino dump toggle poller.
- User-stated (2026-10-26): a `while running do ... task.wait() end` loop spins at about 60 kHz on this build and starves the scheduler. The user's own scripts poll menus at `task.wait(0.15)` and action loops at `task.wait(0.25)`. Proof: Ride A Dino poller and mount loop.
