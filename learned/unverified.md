## Cross-game scripts do not transfer
A working GC stat script from another game is not evidence about this one. The Area51 example (`is_burst`, `shoot_wait`, `inaccuracy`, `fire_rate`, `is_auto`, `bullet_count`, `max_ammo`, `ammo`, `max_stored`, `stored_ammo`) targets lowercase scalar fields in plain readable tables. Realistic Home Defense runs the ACS engine with camelCase fields (`ShootRate`, `camRecoil`, `MinSpread`) and passes every settings table through `LockSettings`. Copying key names across games is guesswork; only the *shape* of the approach transfers.
